A resume website built to showcase my pursuit in a degree of Information Systems and Analytics with a concentration in Cyber Risk at LSU.

Here is a link to my live website: https://dalila-granados.github.io/Dalila-Website/index.html

When building this site, I didn't initially understand why my contact form wasn't working. I was confused when every submission showed an error instead of sending me an email. I asked the coding agent why it wasn't working, and it let me know that websites have no built-in mail server. This made complete sense, so it then requested my help in activating a "FormSubmit One-Time Activation." With this, I am now able to receive emails every time someone sends me a completed form, and the user also gets a verification stating that their message was sent. That additional portion that the coding agent handled by itself was very helpful for me because now the user can see that their message was actually sent!
